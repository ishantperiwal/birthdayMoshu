# Moon surface map

`moon-lroc.jpg` is NASA's 2019 LROC color map, downloaded unchanged from:
https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_poles_1k.jpg

Credit: NASA's Scientific Visualization Studio. CGI Moon Kit by Ernie Wright,
using the Lunar Reconnaissance Orbiter Camera team's WAC mosaic.
Source and credits: https://svs.gsfc.nasa.gov/4720/

The sky shader projects the map onto the existing moon and uses it only as subtle
brightness variation at night. The daytime sun is unchanged.
